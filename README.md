# کافه‌کتاب سیمرغ

نسخه جدید اپلیکیشن سیمرغ با رابط فارسی RTL، مبتنی بر HTML/CSS/JS و Capacitor، به‌همراه API جدید Express و PostgreSQL.

## ساختار پروژه
- `www/v2/`: رابط کاربری نسخه جدید
- `www/index.html`: ورودی برنامه و هدایت به رابط جدید
- `server/v2/`: سرور جدید، ساختار PostgreSQL و ابزارهای مدیریت دیتابیس
- `scripts/check-v2.js`: بررسی syntax رابط کاربری
- `.github/workflows/`: بررسی کد و ساخت APK

کد و سرور قدیمی از این شاخه حذف شده‌اند. برای توسعه فقط از `server/v2` استفاده کنید.

## استقرار API روی چابکان
- Root Directory: `server/v2`
- Install Command: `npm install`
- Start Command: `npm start`
- Node.js: نسخه 20 یا بالاتر

متغیرهای محیطی موردنیاز:
- `DATABASE_URL`: رشته اتصال PostgreSQL
- `JWT_SECRET`: کلید محرمانه طولانی
- `DB_SSL=true` در صورت نیاز سرویس دیتابیس به SSL
- `CORS_ORIGIN`: دامنه‌های مجاز اپ/وب، در صورت محدودسازی CORS
- `PORT`: پورت ارائه‌شده توسط میزبان

مقادیر محرمانه را در GitHub یا کد قرار ندهید.

## دیتابیس
ساختار نهایی دیتابیس در `server/v2/schema.sql` است. راهنمای اجرای آن در pgAdmin در `server/v2/README.md` قرار دارد.

برای مقداردهی schema از محیط سرور:
```bash
npm run db:init
```

برای ساخت مدیر اولیه:
```bash
npm run admin:seed
```
ابزار seed باید با متغیرهای محیطی امن و طبق راهنمای `server/v2/README.md` اجرا شود.

## اجرای بررسی‌ها
در ریشه پروژه:
```bash
npm install
npm run check
```

## ساخت APK
از GitHub Actions، workflow ساخت APK را اجرا کنید. خروجی فعلی workflow برای آزمایش است؛ پیش از انتشار عمومی باید نسخه Release و امضای معتبر آماده شود.

## وضعیت فعلی
رابط `www/v2` هنوز نمونه اولیه تعاملی با داده‌های نمایشی مرورگر است و اتصال کامل به API انجام نشده است. API نیز هنوز همه endpointهای احراز هویت، مدیریت، کافه، فروشگاه، کتابخانه، رویدادها و تالار را پیاده‌سازی نکرده است. پیش از استفاده واقعی، این بخش‌ها باید تکمیل و آزمون شوند.
